## 3. What it takes to turn a picture into an in-game OC look

reports\oc-design.md section 4 planned the OC body as a code-drawn blob (`drawOcBody`: silhouette + palette colour + pattern + eyes + mouth + hat; "No PNGs"). Switching to pictures means the look becomes a sprite, so the work moves to the existing sprite path:

1. **Approval and download.** The owner OKs each file by name (table above); only then is it fetched. Keep the wiki file name in a credits list so the source is traceable.
2. **Make it a sprite like the roster's.** Existing fighter PNGs are small: firey.png is 150x200 px and 18.5 KB, firey-jr.png 241x200 / 19.9 KB (assets\sprites, 400 files, plus attacks\, items\, skins\, thumbs\). Crop each render to its content, scale to about 200 px tall, keep alpha, compress to roughly 20 KB. Name them `oc-<slug>.png` in assets\sprites so they are easy to find and exclude from fighter manifests.
3. **Register them.** Add the files to the sprite preload / `SPRITES[...]` table the renderer reads (the blob fallback kicks in whenever `SPRITES[name]` is missing, so a missing file degrades gracefully). Give OCs a `look.img` index into a **fixed shipped list of 8 to 12 looks** instead of the `look.c/p/e/m` fields; keep `look.hat` so wardrobe hats still stack (`drawCosHat` needs only a top line and an eye line: measure them per picture once, store with the look).
4. **Hitboxes stay fixed.** Keep the 24 px circle hurtbox for every OC (`hurtboxFor` null fallback) so a tall thin look (MePhone7, USB, Pastel Feather) and a wide one (Bandana, Hay Bale) hit identically; draw the picture scaled to fit a fixed box (about 2 x f.r tall, centred), so wide looks shrink rather than overflow.
5. **Online.** `cosNetCode` carries the look as a compact position code; because the picture list is fixed and shipped with the game, the index is enough and both clients have the file. Never touch the live relay for this.
6. **Credits.** Add a line to the Thanks roll: character designs from BFDI Mini (jacknjellify) and Inanimate Insanity Infinity (AnimationEpic), used in a free fan game; wiki file names as the source.
7. **Skip for the OC editor.** The "Look" step becomes a picker over the shipped pictures (the 3-looks-per-OC rule from section 4 still works).
