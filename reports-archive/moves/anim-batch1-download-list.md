# Batch 1 download list (animation plan)

This is the list to approve before anything is downloaded. **No image was downloaded or saved.** Every row below was looked up through the wikis' own file data (name, pixel size, file size). Nobody has looked at the pictures yet.

Sources: BFDI wiki (battlefordreamisland.fandom.com) for Donut, Sidewalky, Lollipop and Bell. Inanimate Insanity wiki (inanimateinsanity.fandom.com) for Box, Tissues, Goo, Paintbrush and Teddy Bear. The fighters and poses come from `animation-plan.md` (Section 5, suggested batch 1).

**What was found.** Every file name in the plan exists under that exact name, so no name had to be swapped for a close match. Some sets are bigger than the plan said:

- Lollipop's screech has 20 frames, not 15.
- Sidewalky's falling set has 7 frames, not 5. The two missing middle frames are `Sidewalky falling 3.png` and `Sidewalky falling 4.png`.
- Each Donut face comes in 3 frames.

Those extra frames are marked **extra**. No file in this list is fan-made or gory. The fan-made `Lollipop Fanmade New Body.png` on Lollipop's gallery was left out.

**How to read the tables:**

- Each file is marked **core** (the plan's pick), **alt** (the other half of an "or" in the plan; pick one) or **extra** (more frames of a set the plan named).
- Pixels are the file's full size. The game shrinks pictures to 200px tall, so big files get smaller after fetching.
- "Episode frame" means a scene picture with a background or other characters in it, which needs cutting out by hand.
