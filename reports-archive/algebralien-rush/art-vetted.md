# Algebralien Rush: the 20 wiki renders (downloaded and vetted 2026-11-02)

The owner said "Yes, all 20" in a question box that named each file and its size (about 5.1 MB, the Battle for Dream Island wiki, static.wikia.nocookie.net). Only these 20 files were downloaded: no other file may be downloaded without a new OK.

Fetched with `format=original` (without it the wiki's CDN serves WebP). Each file is a real PNG, RGBA, with all four corners alpha 0 (checked by a script) and was LOOKED AT by the lead. Staged copies: `reports/algebralien-rush/art-vetted/` (file names have spaces and punctuation replaced by `_`). Builders: you may copy from there instead of re-fetching, but still add the `scripts/fetch-sprites.mjs` pick and the `CREDITS.md` row (the unaffiliated-fan-work wording) for every file you use, and scale them the project's way (about 200 px tall for a boss).
